# ✳ Vedic Multiplier — Fast Multiplication Calculator

### Ancient Wisdom. Modern Speed.

A modern, interactive multiplication calculator based on **Vedic Mathematics**, using the **Urdhva Tiryagbhyam (Vertically and Crosswise)** multiplication technique.

Built with HTML, CSS, and JavaScript, this project combines traditional mathematical techniques with a clean, responsive user interface and step-by-step calculation explanations.

---

## About the Project

Vedic Multiplier is a web-based calculator designed to demonstrate how multiplication can be performed using the Urdhva Tiryagbhyam sutra of Vedic Mathematics.

Instead of relying on JavaScript's built-in multiplication operator for the calculation, the application processes individual digits, computes vertical and crosswise products, and propagates carries to obtain the final answer.

The goal is to make mathematical calculations interactive, understandable, and accessible to students and mathematics enthusiasts.

## Features

- **Vedic Multiplication Algorithm:** Implements the Urdhva Tiryagbhyam method using digit-wise calculations.
- **Step-by-Step Explanation:** Displays diagonal products, intermediate sums, and carry values.
- **Modern User Interface:** Dark theme with gradient text, glowing backgrounds, and a clean layout.
- **Responsive Design:** Works on desktop, tablet, and mobile screens.
- **Input Validation:** Accepts non-negative whole numbers containing up to 30 digits.
- **Instant Results:** Calculates and displays the product directly in the browser.
- **Indian Number Formatting:** Displays large numbers using the Indian comma-separation system.
- **Copy Result:** Copies the calculated product to the clipboard.
- **Swap Numbers:** Quickly exchanges the two input values.
- **Clear Calculator:** Resets the inputs and results.
- **No Backend Required:** Runs entirely in the browser.

## About Urdhva Tiryagbhyam

Urdhva Tiryagbhyam is a Sanskrit expression meaning **"Vertically and Crosswise."**

It is a multiplication technique associated with Vedic Mathematics in which digit products are arranged into successive diagonals. The diagonal products are added together, and carries are transferred to the next position.

For example:

**123 × 456 = 56,088**

The multiplication process includes:

1. Vertical multiplication of the rightmost digits.
2. Crosswise multiplication of adjacent digits.
3. Combining products along successive diagonals.
4. Applying carry propagation.
5. Combining the resulting digits to obtain the final product.

This project uses these principles to demonstrate the calculation process for numbers of different lengths.
